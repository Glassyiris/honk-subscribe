# honk-subsribe

Clash and sing-box exports preserve the TLS required by Trojan, AnyTLS, Hysteria2, TUIC and Juicity, even when the legacy node model's optional `tls` flag is `false`. Optional VMess/VLESS TLS and REALITY settings, existing credentials and certificate-verification options remain unchanged. No stored node or ID rewrite is required.

See [the Chinese guide](README_CN.md) for setup and usage.
